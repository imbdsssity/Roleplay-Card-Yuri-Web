# Roleplay Archive

Foundation for a bilingual archive of SillyTavern character cards, World Books and TavernWeave-Yuri. This repository currently contains an unlaunched Phase 0 scaffold, not the finished website.

See [the project handoff](docs/WEBSITE_SPEC_AND_HANDOFF.md) and [contributing guide](docs/CONTRIBUTING.md) for the content contract, workstream boundaries, checks and publication gate. Source collections and original files are private until reviewed and approved.
